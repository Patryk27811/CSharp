# Klasa Rectangle

Program w C#, który oblicza pole i obwód prostokąta na podstawie danych wprowadzonych przez użytkownika.
Zawiera klasę Rectangle z metodami Area() i Perimeter(), które mogą być testowane jednostkowo przy użyciu xUnit.

---

## 🔧 Funkcjonalność

Użytkownik wprowadza szerokość i wysokość prostokąta z klawiatury.

Program oblicza i wyświetla:

pole prostokąta (Area()),

obwód prostokąta (Perimeter()).

klasa Rectangle zawiera tylko niezbędne metody i może być łatwo testowana jednostkowo.

## Uruchomienie

1. Otwórz terminal w katalogu projektu.
2. Uruchom komendę:
   dotnet run --project src/src.csproj
