# Klasa Rectangle

Program w C#, który oblicza pole i obwód prostokąta.
Zawiera klasę `Rectangle` z konstruktorem ustawiającym wymiary, oraz metody `Area()` i `Perimeter()`.

---

## 🔧 Funkcjonalność

- Użytkownik podaje szerokość i wysokość prostokąta.
- Program tworzy obiekt klasy `Rectangle` z podanymi wartościami.
- Program oblicza i wyświetla:
  - pole prostokąta (`Area()`),
  - obwód prostokąta (`Perimeter()`).
- Klasa `Rectangle` może być testowana niezależnie w projekcie testowym.

## Uruchomienie

1. Otwórz terminal w katalogu projektu.
2. Uruchom komendę:
   dotnet run --project src/src.csproj
