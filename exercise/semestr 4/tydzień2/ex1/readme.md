# LINQ: Join – łączenie dwóch kolekcji

Program konsolowy w C# (.NET), który pokazuje jak łączyć dwie kolekcje za pomocą operacji `Join` z LINQ.

---

## Funkcjonalność

- Definiuje rekordy `Pracownik` i `Dzial`.
- Metoda `JoinPracownicyDzialy` łączy pracowników z działami po kluczu `DzialId`.
- Zwraca listę sformatowanych par "Imię - Nazwa działu".
- Wyświetla wyniki w konsoli.

---

## Uruchomienie

1. Otwórz terminal w katalogu projektu.
2. Uruchom komendę:
   dotnet run --project src/src.csproj
