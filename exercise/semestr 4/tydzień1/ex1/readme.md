# LINQ: Wybieranie parzystych liczb z tablicy

Prosty program konsolowy w C# (.NET), który demonstruje użycie LINQ do filtrowania elementów tablicy.

---

## Funkcjonalność

- Program definiuje tablicę liczb całkowitych.
- Za pomocą metody `Where` z LINQ wybiera tylko liczby parzyste.
- Wyświetla przefiltrowane wyniki w konsoli.

---

## Uruchomienie

1. Otwórz terminal w katalogu projektu.
2. Uruchom komendę:
   dotnet run --project src/src.csproj
