# LINQ: Obliczanie średniej z tablicy

Program konsolowy w C# (.NET) obliczający średnią arytmetyczną z tablicy liczb całkowitych przy użyciu LINQ.

---

## Funkcjonalność

- Metoda `ObliczSrednia` przyjmuje tablicę liczb całkowitych.
- Używa metody `Average()` z LINQ do obliczenia średniej.
- Waliduje wejście – rzuca `ArgumentException` dla pustej lub null tablicy.
- Wynik jest wyświetlany w konsoli.

---

## Uruchomienie

1. Otwórz terminal w katalogu projektu.
2. Uruchom komendę:
   dotnet run --project src/src.csproj
