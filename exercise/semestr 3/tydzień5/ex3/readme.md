# Program do Odwracania Ciągu Znaków (ReverseString)

Prosty program konsolowy w C#, który prosi użytkownika o podanie tekstu, a następnie odwraca jego kolejność.

---

## Funkcjonalność

Program prosi użytkownika o podanie dowolnego ciągu znaków (`Console.ReadLine()`).

- Implementuje funkcję `ReverseString(string s)`.
- Funkcja konwertuje wejściowy tekst na tablicę znaków (`ToCharArray()`).
- Używa `Array.Reverse()` do odwrócenia kolejności elementów w tablicy.
- Zwraca nowy ciąg znaków (`string`) utworzony z odwróconej tablicy.
- Program wyświetla wynik w konsoli.

---

## Uruchomienie

1. Otwórz terminal w katalogu projektu.
2. Uruchom komendę:
   dotnet run --project src/src.csproj
