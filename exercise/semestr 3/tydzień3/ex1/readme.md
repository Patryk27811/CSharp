# Funkcja IsPrime(int n)

Program w C#, który generuje 100 liczb losowych z przedziału 0–10000 i znajduje największą wartość wśród nich.

---

## 🔧 Funkcjonalność

Program losuje 100 liczb całkowitych z zakresu 0–10000.

Wszystkie liczby są wypisywane w konsoli.

Program znajduje i wyświetla największą wartość w wygenerowanym ciągu.

Logika znajdowania maksimum może być wykorzystana w testach jednostkowych.

---

## Uruchomienie

1. Otwórz terminal w katalogu projektu.
2. Uruchom komendę:
   dotnet run --project src/src.csproj
