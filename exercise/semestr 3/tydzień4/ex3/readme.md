# Program Person i Student (Sortowanie)

Program w C# demonstrujący dziedziczenie (`Person`, `Student`) oraz sortowanie listy obiektów za pomocą LINQ.

---

## Funkcjonalność

- Definiuje klasę bazową `Person` i pochodną `Student`.
- Pokazuje polimorfizm, przechowując obiekty obu typów na jednej liście (`List<Person>`).
- Implementuje sortowanie listy alfabetycznie po nazwisku (`LastName`) przy użyciu `OrderBy`.

---

## Uruchomienie

1. Otwórz terminal w katalogu projektu.
2. Uruchom komendę:
   dotnet run --project src/src.csproj
